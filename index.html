Google Maps API キーを入力して始める

🔒 プライバシー保護：キーはこのブラウザの localStorage に保存されます。このアプリからは Google Maps API への認証以外の目的で外部に送信しません。
  1. Google Cloud Console を開き、プロジェクトを作成（または選択）する
  2. 左メニュー「APIとサービス」→「ライブラリ」を開く
  3. Maps JavaScript API を検索して「有効にする」
  4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」
  5. 発行されたキーをコピーして上の欄に貼り付ける
💳 料金：Google Maps Platform の利用には請求先アカウントと支払い方法の設定が必要です。StreetGuess で主に使う無料枠は Dynamic Maps が月 10,000 回、Dynamic Street View が月 5,000 回です。課金を避けたい場合は、専用プロジェクトで Maps JavaScript API の割り当て上限を無料枠以下に下げてください。

🔒 キーの利用元制限：必須ではありませんが、API キーを使えるサイトを制限できます。この公開ページで遊ぶ場合は「アプリケーションの制限」→「ウェブサイト」に https://budoucha.github.io/* を追加します。別の場所で公開する場合は、実際に公開する URL を許可先にしてください。「API の制限」は Maps JavaScript API のみにします。ブラウザ上で API 認証に使われるキーは開発者ツール等で確認できるため、不安がある場合は StreetGuess 専用キーを使ってください。

💾 入力したキーはこのブラウザの localStorage に保存されます。ファイルを再度開いても入力不要です。
